# studies/regimes/results/

Output files from the operating-regime discovery study (`studies/regimes/`).

| File | Contents | Generated by |
|---|---|---|
| `results_regimes.txt` | Full analysis results: dataset digest, outcome distribution, embedding quality, SGS variable ranking, early-window classifier accuracy and baselines. | `python -m studies.regimes.analysis data/regimes` |

Every number in Table I, Table III, and Section V of the ACC 2027 paper is transcribed from this file.

Do not edit this file by hand. Regenerate with the commands in `studies/regimes/README.md`. Note that t-SNE, PaCMAP, and HDBSCAN are stochastic and their output may differ in the last digits on a different platform or BLAS build, even with seeds set.
