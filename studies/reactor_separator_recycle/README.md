# studies/reactor_separator_recycle/

Reference results and the heat-exchanger network design comparison for the `reactor_separator_recycle` case. Every number in Sections II and IV of the ACC 2027 paper and in Table II comes from `results/`.

## Reproduction

```bash
.venv/Scripts/python -m studies.reactor_separator_recycle.reference   # ~20 s; writes results/reference.txt
.venv/Scripts/python -m studies.reactor_separator_recycle.designs     # several minutes; writes results/designs.txt
```

## Files

| File | Contents |
|---|---|
| `reference.py` | Reproduces every number cited in the write-up: reactor eigenvalues at three steady states, recycle amplification under each of the four regulatory structures, and the steady-state stream table. Writes `results/reference.txt`. Run as a module: `python -m studies.reactor_separator_recycle.reference`. |
| `designs.py` | Full design comparison: runs each heat-exchanger network (none, D1, D3, D4, D5) through the throughput disturbance, computes damping ratios and economics, and writes `results/designs.txt` and figures. Also caches a `designs.pkl` for `acc_figures.py` to redraw from. Run as a module: `python -m studies.reactor_separator_recycle.designs`. |
| `flowsheets.py` | Draws the flowsheet diagram and the four control-structure diagrams as PNG/SVG (or PDF/EPS at print resolution). These figures appear in the paper but are not regenerated by the study automation. |

## results/

| File | Paper location |
|---|---|
| `reference.txt` | Section II (reactor eigenvalues); Section IV (recycle amplification under each structure) |
| `designs.txt` | Table II; Section IV (tuning, retuning of D4, throughput response); Fig. 2 |
