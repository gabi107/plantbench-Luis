# studies/reactor_separator_recycle/results/

Committed reference output files for the `reactor_separator_recycle` study. Every number in the ACC 2027 paper that comes from this study is transcribed from one of these files.

| File | Contents | Generated by |
|---|---|---|
| `reference.txt` | Reactor eigenvalues at three steady states; recycle amplification under the four regulatory structures; steady-state stream table. | `python -m studies.reactor_separator_recycle.reference` |
| `designs.txt` | Damping ratios, economics and closed-loop throughput responses for the five heat-exchanger networks. | `python -m studies.reactor_separator_recycle.designs` |

`tests/cases/reactor_separator_recycle/test_golden.py` checks that regenerating these files produces byte-for-byte identical output on the reference platform. Do not edit these files by hand.
