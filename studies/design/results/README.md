# studies/design/results/

Output files from the design sensitivity study (`studies/design/`).

| File | Contents | Generated by |
|---|---|---|
| `results_design.txt` | Damping ratio vs. analyzer deadtime sweep and Sobol' first-order / total sensitivity indices over the five-parameter design box. | `python -m studies.design.analysis` |
| `sobol-outcome.json` | Raw integration outcomes (damping ratios) for the Sobol' quasi-random sample. Intermediate file consumed by `analysis.py` on its second pass. | `python -m studies.design.verify` |

Do not edit these files by hand. Regenerate with the commands in `studies/design/README.md`.
