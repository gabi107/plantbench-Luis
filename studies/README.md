# studies/

Scripts that use the `plantbench` library to generate and analyse the datasets reported in the ACC 2027 paper. The library never imports from `studies/`; `tests/test_architecture.py` enforces this.

Studies must be run in a specific order because later steps depend on datasets generated by earlier ones. See `README.md` at the repository root for the full reproduction sequence.

## Top-level files

| File | Contents |
|---|---|
| `acc_figures.py` | Assembles the three figures of the ACC 2027 paper from cached results. Must be run after all three studies have completed. Writes PNGs to `figures/acc/`. |
| `paper_style.py` | Shared matplotlib style: sets figure dimensions to the paper's one-column and two-column widths, font sizes, and colour cycle. Imported by every figure-drawing script. |

## Subdirectories

| Directory | Study | What it produces |
|---|---|---|
| `reactor_separator_recycle/` | Reference results and design comparison | `results/reference.txt`, `results/designs.txt`, design-comparison figures |
| `regimes/` | Operating-regime discovery on the closed-loop dataset | `results/results_regimes.txt`, embedding and SGS figures |
| `design/` | Damping ratio vs. analyzer deadtime; Sobol' sensitivity indices | `results/results_design.txt`, deadtime-sweep figure |

Each study subdirectory has its own README with the reproduction commands, the decisions made during the analysis, and a table mapping results files to paper sections.
