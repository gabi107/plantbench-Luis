# docs/cases/

Sphinx documentation pages for the built-in cases, one file per case. These pages appear on the documentation site under the Cases section.

| File | Contents |
|---|---|
| `index.md` | Cases index page: links to each case's documentation page. |
| `jacketed_cstr.md` | Documentation page for `jacketed_cstr`: states, options, structures, disturbances and reference values, sourced from the case card `plantbench/cases/jacketed_cstr/README.md`. |
| `reactor_separator_recycle.md` | Documentation page for `reactor_separator_recycle`: the full reactor–separator–recycle plant description, sourced from `plantbench/cases/reactor_separator_recycle/README.md`. |

The authoritative case card for each case lives in `plantbench/cases/<case>/README.md`. These files cross-reference it.
