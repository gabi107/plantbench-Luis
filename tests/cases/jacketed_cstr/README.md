# tests/cases/jacketed_cstr/

Case-specific tests for the `jacketed_cstr` built-in case.

| File | Contents |
|---|---|
| `test_jacketed_cstr.py` | Verifies the `jacketed_cstr` case against its published reference values from Romagnoli & Palazoglu (2020): the steady-state concentrations and temperatures at the reference operating point, and the open-loop eigenvalues at that point. Also checks mass and energy conservation at steady state. |
